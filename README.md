# Тактиль — магазин механических клавиатур

Тема: «HTML и CSS: разработка многостраничного сайта».

В проекте реализован многостраничный HTML/CSS-сайт интернет-магазина механических клавиатур, свитчей, кейкапов и аксессуаров. Фреймворки не используются. JavaScript нужен только для открытия и закрытия модального окна.

## Структура проекта

```
kr1-html-css-shop/
├── index.html      главная страница
├── catalog.html    каталог
├── product.html    карточка товара
├── order.html      форма заявки
├── contacts.html   контакты и обратная связь
├── css/
│   └── style.css   все стили сайта
├── js/
│   └── main.js     открытие и закрытие модального окна
├── images/         SVG-изображения товаров
├── README.md
└── .gitignore
```

## Используемые технологии

- HTML5 и семантическая разметка
- CSS3: переменные, Flexbox, Grid, позиционирование
- методология БЭМ для именования классов
- минимальный JavaScript для элемента `<dialog>`
- GitHub и GitHub Pages

## Обязательные страницы

| Страница | Содержание |
|---|---|
| `index.html` | hero-блок, преимущества, популярные товары, акция, частые вопросы |
| `catalog.html` | категории, статический блок фильтров, карточки товаров |
| `product.html` | изображение, описание, цена, таблица сравнения, отзывы, модальное окно |
| `order.html` | форма заявки с выбором товара |
| `contacts.html` | контакты, схема, форма обратной связи |

На каждой странице есть уникальные `title` и `meta description`, единая навигация, общий `css/style.css`, один тег `main`, шапка и подвал.

## Где что реализовано

- **Семантика:** `header`, `nav`, `main`, `section`, `article`, `aside`, `footer`.
- **Якорные ссылки:** `index.html#advantages`, `#popular`, `#faq`, `#contacts`; ссылки по категориям каталога `#keyboards`, `#parts`.
- **Карточки:** `catalog.html` и `index.html`, с бейджами «Хит», «Новинка», «Скидка».
- **Таблица:** `product.html`, есть `caption`, `thead`, `tbody`, `th`, `td`.
- **Формы:** `order.html`, `contacts.html` и модальное окно в `product.html`. У полей есть `label` (`for` = `id`), `name`, `required`, `type="email"`.
- **Модальное окно:** `<dialog>` в `product.html`, открывается кнопкой «Быстрая заявка».
- **CSS-переменные:** блок `:root` в начале `style.css`.
- **Состояния:** `:hover`, `:focus-visible`, `:disabled`, `.button--disabled`.
- **Flexbox:** меню, группы кнопок, шапка, подвал карточки.
- **Grid:** сетка карточек, каталог с фильтрами, hero-клавиатура, таблица характеристик страницы товара, формы.
- **БЭМ:** `site-header__logo`, `site-nav__link--active`, `product-card__title`, `product-card--discount`, `order-form__field` и другие.
- **Позиционирование:** `relative` у карточки, `absolute` у бейджа, `sticky` у шапки и фильтров, `fixed` у кнопки «Наверх», `z-index` у модалки и шапки.

## Самостоятельные доработки

- собственная визуальная концепция: клавиатура из клавиш на CSS Grid в hero-блоке
- SVG-иллюстрации товаров, нарисованные кодом
- бейджи и модификаторы карточек: `--discount`, `--featured`, `--sale`, `--new`
- хлебные крошки и ссылка для пропуска навигации
- блок отзывов, FAQ на `<details>`, блок «Что в коробке», акция
- таблица сравнения трёх моделей с подсветкой текущей
- сообщение «Заявка отправлена» на чистом CSS через `:target`
- sticky-блок фильтров и категории-якоря в каталоге
- доступность: видимый фокус, `aria-current`, `aria-label`, подписи ко всем полям
- уважение настройки `prefers-reduced-motion`

## Примечания

- Формы отправляют данные методом GET на ту же страницу, потому что серверной части нет.
- Все кнопки «Подробнее» ведут на одну карточку товара `product.html`, так как это статический сайт.
